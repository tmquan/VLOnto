Rebuild the full graph

The complete knowledge graph is too large for this website and is not published as a separate dataset. Rebuild it from the six public source datasets with the code in the GitHub repository (see its README for the requirements); this site keeps its own downloads above.

git clone https://github.com/tmquan/VLOnto
cd VLOnto
python -m vlonto.cli all

Source datasets on Hugging Face, by TMQuan:

  • tmquan/thuvienphapluat-vn-vbpl
  • tmquan/thuvienphapluat-vn-hdpl
  • tmquan/thuvienphapluat-vn-tnpl
  • tmquan/thuvienphapluat-vn-htpl
  • tmquan/anle-toaan-gov-vn
  • tmquan/cbba-toaan-gov-vn
